17. Math, bits and geometry

DSA home← StringsModern algorithms →

A surprising number of problems have a mathematical shortcut: a formula instead of a loop, modular arithmetic instead of giant numbers, a bit trick instead of a set, a cross product instead of trigonometry. This page collects the essential number theory, combinatorics, bit manipulation and computational geometry for programmers.

Primes and the sieve

  • Trial division: n is prime if no number from 2 to √n divides it. O(√n). Factorising works the same way.
  • Sieve of Eratosthenes: all primes up to n in O(n log log n).
  • Miller-Rabin: a fast probabilistic primality test (deterministic for 64-bit numbers with a fixed set of bases); used to generate RSA keys. AKS (2002) proved primality testing is in P.
  • Pollard's rho: factorises large numbers far faster than trial division.

Sieve of Eratosthenes

def sieve(n):
    is_p = bytearray([1]) * (n + 1); is_p[0:2] = b"\x00\x00"
    for p in range(2, int(n ** 0.5) + 1):
        if is_p[p]: is_p[p*p::p] = bytearray(len(range(p*p, n + 1, p)))
    return [i for i in range(n + 1) if is_p[i]]
# Variants: segmented sieve (primes in a range [L, R] with little memory), linear sieve (also gives smallest prime factors).

def ext_gcd(a, b):                      # returns (g, x, y) with a*x + b*y = g
    if b == 0: return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

def mod_inverse(a, m):
    g, x, _ = ext_gcd(a, m)
    if g != 1: raise ValueError("no inverse")
    return x % m                         # Python 3.8+: pow(a, -1, m)

Matrix exponentiation

Any linear recurrence can be written as a matrix times a vector; raising the matrix to the n-th power by repeated squaring gives the n-th term in O(k³ log n). Fibonacci: [[1,1],[1,0]]n = [[F(n+1), F(n)], [F(n), F(n-1)]].

def mat_mul(A, B, m):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) % m for j in range(len(B[0]))] for i in range(len(A))]
def mat_pow(M, n, m):
    R = [[int(i == j) for j in range(len(M))] for i in range(len(M))]
    while n:
        if n & 1: R = mat_mul(R, M, m)
        M = mat_mul(M, M, m); n >>= 1
    return R
fib = lambda n: mat_pow([[1, 1], [1, 0]], n, 10**9 + 7)[0][1]     # F(10^18) in about 60 steps

Expected value is linear: E[X + Y] = E[X] + E[Y] even for dependent variables, which solves many puzzles ("expected number of fixed points of a random permutation is 1"). The birthday paradox explains hash collisions: with N possible values, a collision is likely after about √N items.

Bit manipulation

Integers are arrays of bits; bitwise operators work on all bits at once. Bit tricks give compact sets (a 64-bit word holds a subset of 64 items), fast arithmetic, and elegant solutions.

Real uses: permissions and feature flags, bitmap indexes in databases, Bloom filters, chess engines (bitboards), compression, checksums and CRC, graphics, and network masks (ip & netmask).

Computational geometry

The workhorse is the cross product of vectors OA and OB: (A.x - O.x)(B.y - O.y) - (A.y - O.y)(B.x - O.x). Positive means B is counter-clockwise (a left turn) from A around O, negative clockwise, zero collinear. It replaces angles and trigonometry in almost every geometric test, using only integer arithmetic.

Convex hull (Andrew's monotone chain)

def cross(o, a, b): return (a[0]-o[0]) * (b[1]-o[1]) - (a[1]-o[1]) * (b[0]-o[0])

def polygon_area(p):                     # shoelace formula; positive if counter-clockwise
    return sum(p[i-1][0] * p[i][1] - p[i][0] * p[i-1][1] for i in range(len(p))) / 2

def segments_intersect(p1, p2, p3, p4):  # proper intersection test (no collinear cases)
    d1, d2 = cross(p3, p4, p1), cross(p3, p4, p2)
    d3, d4 = cross(p1, p2, p3), cross(p1, p2, p4)
    return d1 * d2 < 0 and d3 * d4 < 0

def point_in_polygon(pt, poly):          # ray casting: count edge crossings to the right
    x, y, inside = pt[0], pt[1], False
    for i in range(len(poly)):
        (x1, y1), (x2, y2) = poly[i - 1], poly[i]
        if (y1 > y) != (y2 > y) and x < x1 + (y - y1) * (x2 - x1) / (y2 - y1):
            inside = not inside
    return inside

Floating point pitfalls

0.1 + 0.2 != 0.3. Compare with a tolerance (abs(a - b) < 1e-9), prefer integer cross products when coordinates are integers, use decimal for money, and beware of catastrophic cancellation when subtracting nearly equal numbers.

FFT and fast multiplication

Multiplying two polynomials of degree n naively takes O(n²). The fast Fourier transform evaluates them at special points (complex roots of unity) by divide and conquer in O(n log n), multiplies the values pointwise, and transforms back. The number theoretic transform (NTT) does the same with modular arithmetic, so the results are exact. Uses: big-integer multiplication, signal and image processing, audio (MP3, spectrograms), convolution in neural networks, and string matching with wildcards.

Recent progress: integer multiplication in O(n log n) (Harvey and van der Hoeven, 2019); the matrix multiplication exponent ω keeps creeping down (about 2.371 as of 2024, from Strassen's 2.807 in 1969); and AI systems have discovered new small matrix-multiplication algorithms: DeepMind's AlphaTensor (2022), and AlphaEvolve (2025), which multiplies 4×4 complex matrices with 48 scalar multiplications instead of Strassen's 49.

Real-world use cases

  • Cryptography: RSA (fast modular exponentiation, modular inverses, primes), elliptic-curve cryptography, Diffie-Hellman key exchange.
  • Hashing and checksums: modular arithmetic, CRC with bit operations.
  • Graphics and games: cross and dot products, collision detection, spatial partitioning.
  • Maps and logistics: point-in-polygon for geofencing, nearest neighbours, routing on spatial grids.
  • Signal processing and ML: FFT, convolution, linear algebra.
  • Probability: load balancing, randomised algorithms, A/B test statistics.

Practice questions

Q1. Count primes less than n medium sieve

Sieve of Eratosthenes (animated above): O(n log log n). Testing each number by trial division would be O(n√n).

Q2. Single number (every other number appears twice) easy XOR

functools.reduce(operator.xor, nums): duplicates cancel. O(n), O(1). Variant "every other appears three times": count each bit position modulo 3.

Q3. Missing number in 0..n easy math / XOR

n*(n+1)//2 - sum(nums), or XOR all indexes and values together. O(n), O(1).

Q4. Counting bits for every number up to n easy bit DP

bits[i] = bits[i >> 1] + (i & 1), or bits[i] = bits[i & (i - 1)] + 1. O(n).

Q5. Power of two / power of four easy bit tricks

Power of two: n > 0 and n & (n - 1) == 0. Power of four: also require the single bit at an even position: n & 0x55555555 != 0.

Q6. Add two integers without + or - medium bits

Sum without carry = a ^ b; carry = (a & b) << 1. Repeat until the carry is 0. (In Python, mask to 32 bits to emulate fixed-width integers.)

Q7. GCD of strings easy gcd

Largest string x such that both s and t are repetitions of x.

If s + t != t + s there is none; otherwise the answer is s[:gcd(len(s), len(t))].

Q8. The n-th Fibonacci number for n = 1018 (mod p) hard matrix power

Matrix exponentiation (code above): O(log n) 2×2 multiplications. (Fast doubling identities F(2k) and F(2k+1) do the same with less work.)

Q9. Number of paths in a grid modulo 109+7 medium combinatorics

An r × c grid moving only right/down needs (r-1)+(c-1) moves, of which r-1 are down: C(r + c - 2, r - 1), computed with factorials and modular inverses (code above). O(1) per query after pre-computation.

Q10. Max points on a line hard gcd slopes + hash

For each anchor point, normalise the direction to every other point as (dx/g, dy/g) with a consistent sign (g = gcd), and count equal directions in a hash map. Integer slopes avoid floating-point errors. O(n²).

Q11. Erect the fence (convex hull including collinear points) hard monotone chain

Monotone chain (animated) but pop only when the cross product is strictly negative, so collinear boundary points stay; remove duplicates at the end. O(n log n).

Q12. Rectangle overlap and area easy intervals in 2-D

Two axis-aligned rectangles overlap if their x-intervals and y-intervals both overlap. Intersection area = max(0, min(x2, X2) - max(x1, X1)) * max(0, min(y2, Y2) - max(y1, Y1)).

Q13. Excel column title (1 → A, 28 → AB) easy base conversion 
def title(n):
    s = ""
    while n:
        n, r = divmod(n - 1, 26)          # bijective base 26: no zero digit
        s = chr(65 + r) + s
    return s
Q14. Reverse the bits of a 32-bit integer easy bits

Loop 32 times: res = (res << 1) | (n & 1); n >>= 1. A faster version swaps halves, then quarters, and so on, with masks (5 steps).
