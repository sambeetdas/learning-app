Trie (prefix tree)

Each edge is a character; each path from the root spells a prefix. Looking up or inserting a word costs O(length of the word), regardless of how many words are stored, and all words with a given prefix sit in one subtree.

Insert words, then search a prefix

class Trie:
    def __init__(self): self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word: node = node.setdefault(ch, {})
        node["$"] = True                       # end-of-word marker
    def _walk(self, s):
        node = self.root
        for ch in s:
            if ch not in node: return None
            node = node[ch]
        return node
    def search(self, word): n = self._walk(word); return bool(n and "$" in n)
    def starts_with(self, prefix): return self._walk(prefix) is not None
  • Variants: compressed tries / radix trees (merge single-child chains; used in IP routing tables and the Linux kernel), ternary search trees (less memory), binary tries on the bits of integers (maximum XOR queries), and suffix tries/trees for substring search.
  • Uses: autocomplete and search suggestions, spell checkers, T9 keyboards, longest-prefix match in routers, Aho-Corasick multi-pattern matching (see strings), word games (Boggle, Word Search II).

Union-find (disjoint set union)

Keeps a collection of disjoint sets with two operations: find(x) returns the representative of x's set, and union(a, b) merges two sets. Each set is a tree whose root is the representative.

Union by rank and path compression

class DSU:
    def __init__(self, n): self.p, self.r = list(range(n)), [0] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]         # path halving (iterative compression)
            x = self.p[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b: return False
        if self.r[a] < self.r[b]: a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]: self.r[a] += 1
        return True

Uses: Kruskal's MST, connected components when edges arrive over time, detecting cycles in undirected graphs, image segmentation and percolation, grouping duplicate accounts or entities ("these emails belong to the same person"), and type inference (unification) in compilers.

Segment tree

A binary tree over the array where each node stores a summary (sum, min, max, gcd...) of its range. Any range splits into O(log n) stored nodes, so both queries and updates are O(log n).

Range sum query and point update

  • Lazy propagation: to add v to a whole range, store "pending add v" on the covering nodes and push it down only when a child is visited. Range updates and range queries both stay O(log n).
  • Iterative (bottom-up) segment trees in an array of size 2n are short and very fast.
  • Merge sort tree, persistent segment tree, segment tree beats handle harder queries (k-th smallest in a range, historical versions, chmin updates).

Fenwick tree (binary indexed tree)

A compact alternative for prefix sums with updates. Index i is responsible for a range whose length is the lowest set bit of i; moving by i & -i jumps between responsible nodes. Same O(log n) bounds, a quarter of the code.

class BIT:
    def __init__(self, n): self.t = [0] * (n + 1)
    def add(self, i, v):                 # a[i] += v   (1-indexed)
        while i < len(self.t): self.t[i] += v; i += i & -i
    def prefix(self, i):                 # a[1] + ... + a[i]
        s = 0
        while i > 0: s += self.t[i]; i -= i & -i
        return s
    def range(self, l, r): return self.prefix(r) - self.prefix(l - 1)

Classic use: counting inversions or "how many smaller elements appear after me" by sweeping and querying counts of values seen so far.

Sparse table

For data that never changes, pre-compute the minimum of every range of length 2k. Any range [l, r] is covered by two overlapping power-of-two ranges, and min is idempotent, so a query is O(1).

def build(a):
    st = [a[:]]
    k = 1
    while (1 << k) <= len(a):
        prev = st[-1]; half = 1 << (k - 1)
        st.append([min(prev[i], prev[i + half]) for i in range(len(a) - (1 << k) + 1)])
        k += 1
    return st
def query(st, l, r):                     # inclusive
    k = (r - l + 1).bit_length() - 1
    return min(st[k][l], st[k][r - (1 << k) + 1])

Also: sqrt decomposition (blocks of size √n, simple O(√n) queries and updates) and Mo's algorithm (answer many offline range queries by sorting them cleverly, O((n + q)√n)).

Skip list

A sorted linked list with extra "express lanes": each node is promoted to the next level with probability ½. Searching starts at the top lane and drops down when the next node would overshoot, like taking an express train then a local one. Expected O(log n) for search, insert and delete, with simple code and easy lock-free concurrency.

level 3:  head ----------------------------> 50 -----------------> nil
level 2:  head --------> 20 ---------------> 50 -------> 70 ----> nil
level 1:  head -> 10 -> 20 -> 30 -> 40 -> 50 -> 60 -> 70 -> 80 -> nil

search(x): node = head at the top level
    repeat: move right while next.key < x; then go down one level
    at level 1, the next node is x if x is present

Used in: Redis sorted sets (leaderboards), LevelDB/RocksDB memtables, Java's ConcurrentSkipListMap.

Cache structures: LRU and LFU

  • LRU (least recently used): hash map + doubly linked list; move an item to the front on every access, evict from the back. Full code on the linked lists page.
  • LFU (least frequently used): hash map from key to (value, count), plus a map from count to an ordered set of keys, plus the current minimum count. All operations O(1).
  • Modern policies: ARC, 2Q, TinyLFU / W-TinyLFU (Caffeine for Java) and the 2023 SIEVE algorithm combine recency and frequency for better hit rates than plain LRU, with less overhead.

Practice questions

Q1. Implement a trie medium trie

insert, search and starts_with as in the code above. Each operation is O(L). Space is O(total characters) in the worst case.

Q2. Word Search II (many words in a grid) hard trie + DFS

Insert all words into a trie. DFS from every cell, walking the trie in parallel; stop as soon as the current path is not a prefix of any word. Remove found words (or leaves) from the trie to avoid repeats and speed up later searches.

Q3. Number of provinces (connected components) medium union-find

Union every connected pair; the answer is the number of distinct roots (start with n and decrement on every successful union). Nearly O(n²) for an adjacency matrix, dominated by reading it.

Q4. Accounts merge medium union-find on emails

Union all emails within one account. Then group emails by root, sort each group, and attach the account name. O(N α(N) + N log N).

Q5. Number of islands II (land added over time) hard online union-find

Each new land cell starts a new island (count + 1); union it with each neighbouring land cell, and each successful union reduces the count by 1. Report the count after each addition. O(k α(n)).

Q6. Range sum query, mutable medium Fenwick / segment tree

Fenwick tree: update = add the difference; sumRange = prefix(r) - prefix(l - 1). Both O(log n). (Prefix sums alone would need O(n) per update.)

Q7. Count of smaller numbers after self hard Fenwick tree

Compress values to ranks 1..k. Walk from the right; for each value, the answer is prefix(rank - 1) (how many smaller values were already seen), then add(rank, 1). O(n log n). A modified merge sort also works.

Q8. Range minimum queries on a static array medium sparse table

Sparse table (code above): O(n log n) build, O(1) per query. If the array changes, use a segment tree instead.

Q9. Maximum XOR of two numbers medium binary trie

Insert every number's 31 bits (most significant first) into a binary trie. For each number, walk the trie greedily choosing the opposite bit whenever possible; that builds the maximum XOR partner. O(31·n).

Q10. LFU cache hard design 
from collections import defaultdict, OrderedDict
class LFU:
    def __init__(self, cap):
        self.cap, self.kv, self.freq = cap, {}, {}
        self.by_f = defaultdict(OrderedDict); self.min_f = 0
    def _touch(self, k):
        f = self.freq[k]; del self.by_f[f][k]
        if not self.by_f[f] and self.min_f == f: self.min_f += 1
        self.freq[k] = f + 1; self.by_f[f + 1][k] = None
    def get(self, k):
        if k not in self.kv: return -1
        self._touch(k); return self.kv[k]
    def put(self, k, v):
        if self.cap == 0: return
        if k in self.kv: self.kv[k] = v; self._touch(k); return
        if len(self.kv) == self.cap:
            old, _ = self.by_f[self.min_f].popitem(last=False)   # least frequent, then least recent
            del self.kv[old], self.freq[old]
        self.kv[k], self.freq[k], self.min_f = v, 1, 1
        self.by_f[1][k] = None
Q11. My calendar (no double booking) medium sorted structure

Keep booked intervals in a sorted list (or balanced BST / SortedList). For a new [s, e), find the neighbour before and after with binary search and check overlap. O(log n) per booking (O(n) insert with a plain list).

Q12. Longest word built one letter at a time medium trie / BFS

Insert all words; DFS/BFS from the root visiting only nodes that mark the end of a word; the deepest such node (smallest lexicographically on ties) gives the answer.
