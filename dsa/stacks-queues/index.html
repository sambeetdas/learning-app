Two simple rules that power a lot of computing

Stack: Last In, First Out (LIFO)

Like a pile of plates: you add (push) and remove (pop) only at the top. The last thing added is the first thing out.

Operations: push, pop, peek/top, is_empty, all O(1).

Queue: First In, First Out (FIFO)

Like a line at a shop: join at the back (enqueue), leave from the front (dequeue). The oldest item is served first.

Operations: enqueue, dequeue, front, is_empty, all O(1).

stack = []                 # Python list: append/pop at the end are O(1)
stack.append(1); stack.append(2)
stack.pop()                # 2
stack[-1]                  # peek: 1

from collections import deque
q = deque()                # double-ended queue: O(1) at both ends
q.append(1); q.append(2)   # enqueue at the back
q.popleft()                # dequeue from the front: 1   (never use list.pop(0): it is O(n))

Stack and ring-buffer queue

A ring buffer (circular queue) stores a queue in a fixed array. The head and tail indexes move forward and wrap around with % capacity, so dequeuing never shifts elements. Used for keyboard buffers, audio streams, network cards and log buffers.

The most recent unclosed bracket must be closed first, which is exactly LIFO. The same idea checks HTML/XML tags and nested JSON.

Monotonic stack

A monotonic stack keeps its elements in increasing or decreasing order. When a new element arrives, it pops every element it "beats"; each popped element has just found its answer. It solves "next greater / smaller element", "previous smaller", "how many days until a warmer temperature", "largest rectangle in a histogram" and "stock span", all in O(n).

Next greater element

for each index i, value x:
    while stack not empty and value[top] < x:     // (use > for "next smaller")
        answer[top] = x;  pop
    push i
// remaining indexes have no answer

Monotonic deque: sliding window maximum

To get the maximum of every window of size k, keep a deque of indexes whose values decrease from front to back. The front is the maximum; drop it when it leaves the window, and drop smaller values from the back when a bigger one arrives.

Sliding window maximum

Also used in DP optimisations ("the best of the last k states") and for streaming min/max over recent data.

Classic designs

Min stack: push, pop, top and get_min all in O(1)

Store, alongside each value, the minimum of the stack up to that point.

class MinStack:
    def __init__(self): self.s = []
    def push(self, x): self.s.append((x, min(x, self.s[-1][1]) if self.s else x))
    def pop(self): self.s.pop()
    def top(self): return self.s[-1][0]
    def get_min(self): return self.s[-1][1]

Queue from two stacks (amortised O(1))

Push onto inbox. To dequeue, if outbox is empty, pour everything from inbox into outbox (reversing the order), then pop from outbox. Each element moves at most twice.

class Queue2:
    def __init__(self): self.inbox, self.outbox = [], []
    def push(self, x): self.inbox.append(x)
    def pop(self):
        if not self.outbox:
            while self.inbox: self.outbox.append(self.inbox.pop())
        return self.outbox.pop()

The call stack

Every function call pushes a stack frame (arguments, local variables, return address); returning pops it. Recursion is therefore a stack in disguise, and any recursive algorithm (like DFS) can be rewritten with an explicit stack, which avoids "stack overflow" on very deep inputs. See recursion.

Q5. Daily temperatures medium monotonic stack

For each day, how many days until a warmer temperature?

def daily_temperatures(t):
    res, st = [0] * len(t), []
    for i, x in enumerate(t):
        while st and t[st[-1]] < x:
            j = st.pop(); res[j] = i - j
        st.append(i)
    return res

O(n): next greater element, storing the distance instead of the value.

Q6. Largest rectangle in a histogram hard monotonic stack

Bars have width 1 and heights h. Find the largest rectangle.

Approach

For each bar, the widest rectangle using its full height stretches until the first shorter bar on each side. Keep an increasing stack; when a shorter bar arrives, pop: the popped bar's rectangle ends here and starts just after the new stack top.

def largest_rectangle(h):
    st, best = [], 0
    for i, x in enumerate(h + [0]):           # sentinel 0 flushes the stack
        while st and h[st[-1]] >= x:
            height = h[st.pop()]
            left = st[-1] + 1 if st else 0
            best = max(best, height * (i - left))
        st.append(i)
    return best

O(n). Extension: "maximal rectangle of 1s in a matrix" runs this on each row's running heights.

Q8. Decode string medium stack

"3[a2[c]]" → "accaccacc".

def decode(s):
    st, cur, num = [], "", 0
    for c in s:
        if c.isdigit(): num = num * 10 + int(c)
        elif c == "[": st.append((cur, num)); cur, num = "", 0
        elif c == "]":
            prev, k = st.pop(); cur = prev + cur * k
        else: cur += c
    return cur
Q9. Asteroid collision medium stack simulation

Positive values move right, negative left; when two meet, the smaller explodes (equal: both). What remains?

def asteroids(a):
    st = []
    for x in a:
        alive = True
        while alive and x < 0 and st and st[-1] > 0:
            if st[-1] < -x: st.pop(); continue
            if st[-1] == -x: st.pop()
            alive = False
        if alive: st.append(x)
    return st
Q10. Simplify a Unix path medium stack

"/a/./b/../../c/" → "/c".

def simplify(path):
    st = []
    for part in path.split("/"):
        if part == "..":
            if st: st.pop()
        elif part and part != ".": st.append(part)
    return "/" + "/".join(st)
Q11. Basic calculator with + - and brackets hard stack of signs

Evaluate "1 - (4 + 5 - (2 - 3))".

Approach

Keep a running result and a sign. On "(", push the current result and sign, then start fresh; on ")", the inner result is multiplied by the pushed sign and added to the pushed result.

def calc(s):
    res, num, sign, st = 0, 0, 1, []
    for c in s:
        if c.isdigit(): num = num * 10 + int(c)
        elif c in "+-":
            res += sign * num; num = 0; sign = 1 if c == "+" else -1
        elif c == "(":
            st.append((res, sign)); res, sign = 0, 1
        elif c == ")":
            res += sign * num; num = 0
            prev, sg = st.pop(); res = prev + sg * res
    return res + sign * num
Q12. Design a circular queue medium ring buffer 
class CircularQueue:
    def __init__(self, k): self.a, self.head, self.size = [0] * k, 0, 0
    def enqueue(self, x):
        if self.size == len(self.a): return False
        self.a[(self.head + self.size) % len(self.a)] = x; self.size += 1; return True
    def dequeue(self):
        if not self.size: return False
        self.head = (self.head + 1) % len(self.a); self.size -= 1; return True
    def front(self): return self.a[self.head] if self.size else -1
    def rear(self):  return self.a[(self.head + self.size - 1) % len(self.a)] if self.size else -1

All O(1) (see the ring buffer in the playground).
