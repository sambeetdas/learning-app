What is dynamic programming?

Dynamic programming (DP) solves a problem by combining answers to smaller sub-problems, storing each answer so it is computed only once. It applies when a problem has two properties:

  1. Optimal substructure: the best answer is built from best answers to sub-problems (the shortest route to C through B uses the shortest route to B).
  2. Overlapping sub-problems: the same sub-problems come up again and again (naive Fibonacci recomputes fib(3) many times; see the call tree).

DP routinely turns exponential brute force into polynomial time. It is the technique behind diff tools, spell checkers, DNA alignment, speech recognition, route planning and reinforcement learning.

Top-down: memoisation

Write the natural recursion, then cache results. Only computes the sub-problems actually needed.

from functools import cache
@cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

Bottom-up: tabulation

Fill a table from the smallest sub-problems upwards. No recursion limit; easy to optimise space.

def fib(n):
    a, b = 0, 1                   # keep only the last two values
    for _ in range(n): a, b = b, a + b
    return a

How to design a DP solution

1. STATE       What exactly does dp[...] mean?  ("dp[i] = best total using houses 0..i")
               Choose the smallest set of parameters that determines the answer.
2. TRANSITION  How does a state follow from smaller states?  (a choice: take / skip, which coin, which split)
3. BASE CASES  The smallest states you know directly.
4. ORDER       Fill states so that every dependency is already computed.
5. ANSWER      Which state (or max over states) is the final answer?
6. OPTIMISE    Keep only the rows you need; reconstruct the choices if asked.

Rule of thumb: if you can write a brute-force recursion whose arguments are small numbers or indexes, and the same arguments repeat, memoising it is already a DP.

The knapsack family

Choose items with weights and values to maximise value within a capacity. It models budgets, cargo loading, portfolio selection, and many subset problems in disguise (partition equal subset sum, target sum).

0/1 knapsack table

def knapsack(items, W):              # 0/1, one row, O(W) memory
    dp = [0] * (W + 1)
    for w, v in items:
        for c in range(W, w - 1, -1):     # right to left: each item used at most once
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[W]
# Unbounded knapsack (items reusable, e.g. coin change): loop c from left to right instead.

# Bitmask DP: travelling salesman, O(2^n * n^2)
def tsp(d):
    n = len(d); INF = float('inf')
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0                                  # visited {0}, standing at city 0
    for mask in range(1 << n):
        for last in range(n):
            if dp[mask][last] == INF or not mask >> last & 1: continue
            for nxt in range(n):
                if mask >> nxt & 1: continue
                m2 = mask | 1 << nxt
                dp[m2][nxt] = min(dp[m2][nxt], dp[mask][last] + d[last][nxt])
    return min(dp[(1 << n) - 1][v] + d[v][0] for v in range(n))

Optimisation techniques (advanced)

  • Rolling arrays: keep only the previous row (2-D → 1-D memory).
  • Prefix sums over the previous row to make a sum-over-range transition O(1).
  • Monotonic deque for "max of dp over the last k states" (sliding-window DP).
  • Binary search inside the transition (LIS, weighted interval scheduling).
  • Convex hull trick / Li Chao tree: transitions of the form min(m_j · x + b_j) in O(log n) or O(1) amortised.
  • Divide-and-conquer and Knuth optimisations: when the best split point is monotonic, reduce O(n³) interval DP to O(n²), or O(k n²) to O(k n log n).
  • Bitsets for subset-sum style DPs: process 64 states per machine word.
  • Matrix exponentiation for linear recurrences: the n-th Fibonacci number in O(log n) (see math).

DP vs greedy vs divide and conquer

  • Greedy makes one locally best choice and never looks back; fast, but only correct for special problems (see greedy).
  • Divide and conquer splits into independent sub-problems (merge sort); no overlap, so nothing to cache.
  • DP handles overlapping sub-problems and tries all choices, keeping the best.

Practice questions

Q1. Climbing stairs / Fibonacci easy 1-D

dp[i] = dp[i-1] + dp[i-2]; keep two variables. O(n), O(1). With step sizes from a set S: dp[i] = Σ dp[i - s].

Q2. House robber II (houses in a circle) medium 1-D, two runs

The first and last houses are neighbours. Answer = max(rob(houses[1:]), rob(houses[:-1])), running the linear version (animated) twice.

Q3. Coin change and coin change II medium unbounded knapsack 
def min_coins(coins, amount):
    dp = [0] + [float('inf')] * amount
    for x in range(1, amount + 1):
        for c in coins:
            if c <= x: dp[x] = min(dp[x], dp[x - c] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1

def count_ways(coins, amount):           # combinations: coins in the OUTER loop
    dp = [1] + [0] * amount
    for c in coins:
        for x in range(c, amount + 1): dp[x] += dp[x - c]
    return dp[amount]

Swapping the loops in count_ways would count ordered sequences (permutations) instead of combinations.

Q4. Longest increasing subsequence medium DP / patience

O(n²): dp[i] = 1 + max(dp[j] for j < i if a[j] < a[i]). O(n log n): the tails array with binary search (animated above).

Q5. Longest common subsequence medium 2-D 
def lcs(s, t):
    dp = [[0] * (len(t) + 1) for _ in range(len(s) + 1)]
    for i in range(1, len(s) + 1):
        for j in range(1, len(t) + 1):
            dp[i][j] = dp[i-1][j-1] + 1 if s[i-1] == t[j-1] else max(dp[i-1][j], dp[i][j-1])
    return dp[-1][-1]
Q6. Edit distance hard 2-D

Recurrence animated above: match → diagonal; otherwise 1 + min(delete, insert, replace). O(n·m); O(min(n, m)) memory with two rows.

Q7. Partition equal subset sum medium 0/1 knapsack (boolean) 
def can_partition(a):
    total = sum(a)
    if total % 2: return False
    reach = {0}
    for x in a: reach |= {s + x for s in reach}       # or a bitset: bits |= bits << x
    return total // 2 in reach
Q8. Unique paths with obstacles medium grid 
def unique_paths(grid):
    C = len(grid[0]); dp = [0] * C; dp[0] = 1
    for row in grid:
        for c in range(C):
            if row[c] == 1: dp[c] = 0                 # obstacle
            elif c: dp[c] += dp[c - 1]                # from above (dp[c]) + from the left
    return dp[-1]
Q9. Word break medium 1-D over prefixes 
def word_break(s, words):
    ws, n = set(words), len(s)
    dp = [True] + [False] * n                       # dp[i]: s[:i] can be segmented
    for i in range(1, n + 1):
        dp[i] = any(dp[j] and s[j:i] in ws for j in range(max(0, i - 20), i))   # 20 = longest word
    return dp[n]
Q10. Decode ways medium 1-D

'A'=1 ... 'Z'=26. How many ways to decode a digit string?

dp[i] = (dp[i-1] if s[i-1] != '0') + (dp[i-2] if 10 ≤ int(s[i-2:i]) ≤ 26). Like climbing stairs with conditions. O(n).

Q11. Longest palindromic substring / subsequence medium interval

Subsequence: dp[l][r] = dp[l+1][r-1] + 2 if s[l] == s[r], else max(dp[l+1][r], dp[l][r-1]). Substring: expand around each of the 2n-1 centres in O(n²) with O(1) memory, or Manacher's algorithm in O(n) (see strings).

Q12. Stock trading with cooldown medium state machine 
def max_profit(prices):
    hold, sold, rest = float('-inf'), 0, 0
    for p in prices:
        hold, sold, rest = max(hold, rest - p), hold + p, max(rest, sold)
    return max(sold, rest)

Three states per day: holding a share, just sold (must cool down), resting. Each transition is one line.

Q13. Burst balloons hard interval DP

Bursting balloon i earns left × i × right of its current neighbours. Maximise the total.

Think about the last balloon k burst in (l, r): its neighbours are then the fixed boundaries l and r. dp[l][r] = max over k of dp[l][k] + dp[k][r] + a[l]·a[k]·a[r] (with 1s padded at both ends). O(n³).

Q14. Regular expression matching ('.' and '*') hard two sequences 
def is_match(s, p):
    dp = [[False] * (len(p) + 1) for _ in range(len(s) + 1)]
    dp[0][0] = True
    for j in range(2, len(p) + 1):
        dp[0][j] = p[j-1] == '*' and dp[0][j-2]           # "a*b*" can match ""
    for i in range(1, len(s) + 1):
        for j in range(1, len(p) + 1):
            if p[j-1] == '*':
                dp[i][j] = dp[i][j-2] or (p[j-2] in (s[i-1], '.') and dp[i-1][j])   # zero, or one more
            else:
                dp[i][j] = p[j-1] in (s[i-1], '.') and dp[i-1][j-1]
    return dp[-1][-1]
Q15. Weighted job scheduling hard DP + binary search

Jobs have start, end and profit; choose non-overlapping jobs with maximum profit.

Sort by end time. dp[i] = max(dp[i-1], profit[i] + dp[j]) where j is the last job ending before job i starts, found with binary search. O(n log n). (Unweighted, a greedy works; see greedy.)

Q16. Maximal square of 1s medium grid

dp[r][c] = 1 + min(dp[r-1][c], dp[r][c-1], dp[r-1][c-1]) for a 1-cell: the largest square ending at (r, c). Answer = (max dp)². O(R·C).
