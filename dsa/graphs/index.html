What is a graph?

A graph is a set of vertices (nodes) connected by edges. It models anything with relationships: roads between cities, friendships, web links, flights, dependencies between tasks, states of a puzzle. Trees and linked lists are special graphs. Many problems become easy once you see them as "find a path in a graph".

Breadth-first and depth-first search

BFS (queue)

Explores in rings: all nodes at distance 1, then 2, and so on. Finds shortest paths in unweighted graphs, levels, the minimum number of moves. O(V + E).

DFS (stack / recursion)

Goes as deep as possible before backing up. Finds connectivity, cycles, topological order, components, bridges, and is the skeleton of backtracking. O(V + E).

BFS and DFS step by step

  • Mark nodes as seen when you enqueue them (not when you dequeue), or the same node can enter the queue many times.
  • Multi-source BFS: put all sources in the queue at distance 0 (rotting oranges, distance to the nearest exit).
  • 0-1 BFS: edges of weight 0 or 1; use a deque, pushing weight-0 neighbours to the front. Shortest paths in O(V + E).
  • Bidirectional BFS: search from both ends and meet in the middle; explores about 2·bd/2 instead of bd nodes.
  • Cycle detection: undirected: an edge to a visited node that is not your parent. Directed: an edge to a node currently on the DFS stack (colour nodes white/grey/black).

Shortest paths with weights: Dijkstra

With weights, the path with the fewest edges is not necessarily the cheapest. Dijkstra's algorithm (1956) grows a set of settled nodes in order of distance, using a min-heap. It requires non-negative weights: then the closest unsettled node can never be improved later.

Dijkstra's algorithm

import heapq
def dijkstra(adj, s):
    dist = {s: 0}; pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue        # stale
        for v, w in adj[u]:
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd; heapq.heappush(pq, (nd, v))
    return dist

def bellman_ford(n, edges, s):
    dist = [float('inf')] * n; dist[s] = 0
    for _ in range(n - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]: dist[v] = dist[u] + w
    for u, v, w in edges:                       # one more round
        if dist[u] + w < dist[v]: raise ValueError("negative cycle")
    return dist

def floyd_warshall(d):                          # d[i][j] = weight or inf, d[i][i] = 0
    n = len(d)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]: d[i][j] = d[i][k] + d[k][j]
    return d

Recent research: in 2025 Duan, Mao, Mao, Shu and Yin gave a deterministic algorithm for single-source shortest paths on directed graphs with non-negative weights that runs in O(m log2/3 n), the first to beat Dijkstra's "sorting barrier" (STOC 2025 best paper). It is mainly of theoretical interest so far; Dijkstra with a binary heap remains the practical default.

A* search: pathfinding with a sense of direction

A* is Dijkstra that prefers nodes which look closer to the goal. It orders the frontier by f = g + h, where g is the cost so far and h is an admissible estimate of the remaining cost (it must never over-estimate, e.g. straight-line or Manhattan distance). With such an h, A* still finds an optimal path, but usually explores far fewer nodes.

Used in games, robotics and route planners. Real map routing adds pre-processing (contraction hierarchies, hub labels) to answer continent-scale queries in milliseconds.

Topological sort

A topological order of a DAG lists the vertices so that every edge points forward: every task comes after its prerequisites. It exists exactly when the graph has no cycle.

Kahn's algorithm (BFS on in-degrees)

def topo_dfs(graph):                 # alternative: DFS, prepend each node when it finishes
    order, state = [], {}            # state: 1 = on the stack, 2 = done
    def dfs(u):
        state[u] = 1
        for v in graph[u]:
            if state.get(v) == 1: raise ValueError("cycle")
            if v not in state: dfs(v)
        state[u] = 2; order.append(u)
    for u in graph:
        if u not in state: dfs(u)
    return order[::-1]

Used by build tools (make, MSBuild, Gradle), package managers (npm, pip resolving install order), spreadsheet recalculation, task schedulers (Airflow DAGs) and course planners.

Minimum spanning trees

A spanning tree connects all vertices with V-1 edges and no cycles. The minimum spanning tree (MST) does it with the smallest total weight: the cheapest way to cable a network or pave roads between towns.

def prim(adj, start):
    seen, pq, total = {start}, [(w, v) for v, w in adj[start]], 0
    heapq.heapify(pq)
    while pq and len(seen) < len(adj):
        w, v = heapq.heappop(pq)
        if v in seen: continue
        seen.add(v); total += w
        for x, wx in adj[v]:
            if x not in seen: heapq.heappush(pq, (wx, x))
    return total

More essential graph techniques

  • Connected components: run BFS/DFS from every unvisited node, or use union-find (great when edges arrive one at a time).
  • Bipartite check: 2-colour with BFS; an edge between two nodes of the same colour means an odd cycle, so it is not bipartite.
  • Flood fill / islands: DFS or BFS on a grid, marking cells as visited.
  • State-space search: nodes are configurations (a lock combination, a puzzle board, a word); BFS gives the minimum number of moves.
  • Advanced topics: strongly connected components, bridges and articulation points, maximum flow, matching, Euler paths, LCA and more are on the advanced graphs page.

Real-world use cases

  • Navigation: Google Maps, Waze and logistics planners run Dijkstra/A* variants on road networks with live traffic weights.
  • Networking: OSPF routing uses Dijkstra; BGP is path-vector routing; spanning-tree protocol prevents loops in Ethernet.
  • Social networks: friend suggestions ("friends of friends" = BFS depth 2), influence and community detection.
  • Web: crawlers traverse links (BFS); PageRank scores pages by the link graph.
  • Software: dependency resolution, build order, garbage collectors (mark phase is a graph traversal from roots), deadlock detection (cycles in wait-for graphs).
  • Fraud and security: rings of linked accounts, attack graphs.
  • Knowledge graphs and recommendations: entities and relations; graph neural networks.

Practice questions

Q1. Number of islands medium flood fill 
def num_islands(grid):
    R, C, count = len(grid), len(grid[0]), 0
    def sink(r, c):
        if 0 <= r < R and 0 <= c < C and grid[r][c] == "1":
            grid[r][c] = "0"
            sink(r + 1, c); sink(r - 1, c); sink(r, c + 1); sink(r, c - 1)
    for r in range(R):
        for c in range(C):
            if grid[r][c] == "1": count += 1; sink(r, c)
    return count

O(R·C). Use BFS or an explicit stack for very large grids (recursion depth).

Q2. Clone a graph medium DFS + hash map

DFS from the given node; a map old → copy both prevents infinite loops on cycles and lets you wire neighbours to existing copies. O(V + E).

Q3. Course schedule (can all courses be finished?) medium cycle detection

Build the prerequisite graph and run Kahn's algorithm (animated above). All courses can be finished exactly when the produced order contains every course; otherwise there is a cycle. Course schedule II asks for the order itself. O(V + E).

Q4. Rotting oranges medium multi-source BFS

Each minute, rotten oranges rot their fresh neighbours. Minutes until all are rotten (or -1)?

from collections import deque
def oranges(g):
    R, C = len(g), len(g[0]); q = deque(); fresh = 0
    for r in range(R):
        for c in range(C):
            if g[r][c] == 2: q.append((r, c))
            elif g[r][c] == 1: fresh += 1
    minutes = 0
    while q and fresh:
        for _ in range(len(q)):                     # one BFS level = one minute
            r, c = q.popleft()
            for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
                if 0 <= nr < R and 0 <= nc < C and g[nr][nc] == 1:
                    g[nr][nc] = 2; fresh -= 1; q.append((nr, nc))
        minutes += 1
    return -1 if fresh else minutes
Q5. Word ladder hard BFS on implicit graph

Change one letter at a time, every intermediate word must be in the dictionary. Fewest steps from start to end?

Approach

Words are nodes; neighbours differ by one letter. BFS from the start. To find neighbours fast, map patterns like h*t to the words that match them, or try all 26 letters at each position against a set. Bidirectional BFS speeds it up a lot.

O(N · L²) for N words of length L (with the pattern map).

Q6. Network delay time medium Dijkstra

A signal starts at node k; edges have travel times. How long until every node receives it?

Run Dijkstra from k; the answer is the largest finite distance, or -1 if some node is unreachable. O(E log V).

Q7. Cheapest flights within K stops medium Bellman-Ford rounds

Run Bellman-Ford for exactly K+1 rounds, each round relaxing from a copy of the previous round's distances, so paths use at most K+1 edges. O(K·E). (Dijkstra on (node, stops) states also works.)

def cheapest(n, flights, src, dst, k):
    d = [float('inf')] * n; d[src] = 0
    for _ in range(k + 1):
        nd = d[:]
        for u, v, w in flights:
            if d[u] + w < nd[v]: nd[v] = d[u] + w
        d = nd
    return -1 if d[dst] == float('inf') else d[dst]
Q8. Redundant connection medium union-find

A tree with one extra edge added. Which edge creates the cycle?

Process edges in order with union-find; the first edge whose endpoints are already in the same set is the answer. Nearly O(E). See union-find.

Q9. Min cost to connect all points medium MST

Points are a complete graph with Manhattan-distance weights. Prim's algorithm with an O(V²) array scan (no heap needed for a dense graph) or Kruskal on all V²/2 edges.

Q10. Is the graph bipartite? medium 2-colouring 
def bipartite(adj):
    color = {}
    for s in adj:
        if s in color: continue
        color[s] = 0; q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if v not in color: color[v] = 1 - color[u]; q.append(v)
                elif color[v] == color[u]: return False
    return True
Q11. Pacific Atlantic water flow medium reverse BFS

Which cells can drain to both oceans (water flows to equal or lower neighbours)?

Think backwards: BFS/DFS uphill from each ocean's border cells, collecting the cells each ocean can reach. Return the intersection. O(R·C) instead of a search from every cell.

Q12. Path with minimum effort medium Dijkstra on a grid

A path's effort is its largest height difference between neighbouring cells. Minimise it from top-left to bottom-right.

Dijkstra where the "distance" is the maximum edge on the path: nd = max(d, |h[u] - h[v]|). Also solvable with binary search on the answer + BFS, or union-find adding edges in order of weight.

Q13. Alien dictionary hard topological sort

Words are sorted in an unknown alphabet. Recover a valid letter order.

Compare each adjacent pair of words: the first differing letter gives an edge a → b. (If a word is followed by its own prefix, the input is invalid.) Topologically sort the letters; a cycle means no valid order.

Q14. Shortest path in a binary matrix medium BFS, 8 directions

BFS from (0, 0) over cells with value 0, moving in 8 directions; the BFS level at which you reach the corner is the answer. O(n²).
