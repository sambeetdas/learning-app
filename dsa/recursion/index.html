Recursion: solving a problem with a smaller copy of itself

A recursive function calls itself on a smaller input. Every recursive solution has two parts:

  1. Base case: a small input answered directly (an empty list, n = 0, a leaf). Without it the recursion never stops.
  2. Recursive case: express the answer using answers to smaller inputs, and trust that the recursive call works (the "recursive leap of faith").
def factorial(n):
    if n <= 1: return 1                 # base case
    return n * factorial(n - 1)         # recursive case

def sum_list(a):
    return 0 if not a else a[0] + sum_list(a[1:])

Recursion is the natural way to handle recursive structures (trees, nested folders, JSON, grammars) and divide-and-conquer algorithms (merge sort, quicksort, binary search).

The call tree and the call stack

Each call gets its own stack frame with its own local variables. Drawing every call as a node gives the recursion tree; the number of nodes is the time, and its height is the stack space.

Recursion pitfalls

  • Stack overflow: each call uses stack memory. Python stops at about 1000 levels by default (sys.setrecursionlimit raises it, carefully); C#/Java threads have around 1 MB of stack. Deep recursion on big inputs (a 100,000-node linked list, a skewed tree) should be converted to a loop with an explicit stack.
  • Repeated work: naive Fibonacci recomputes the same values exponentially often. Memoise (see DP).
  • Hidden copying: a[1:] copies the list each call, turning O(n) into O(n²). Pass indexes instead.
  • Tail calls: Python, Java and C# do not optimise tail recursion, so a tail-recursive function still uses O(n) stack. (Scheme, Scala with @tailrec, and some C++ compilers do.)
# the same DFS, recursive and with an explicit stack
def dfs_rec(node):
    visit(node)
    for child in node.children: dfs_rec(child)

def dfs_iter(root):
    stack = [root]
    while stack:
        node = stack.pop(); visit(node)
        stack.extend(reversed(node.children))   # reversed keeps the same order

Backtracking

Backtracking builds a solution one choice at a time and abandons ("backtracks" from) a partial solution as soon as it cannot lead to a valid answer. It explores the tree of all possible choices, but prunes whole branches early. It solves puzzles, combinatorial search and constraint problems. 

backtrack(state):
    if state is a complete solution:
        record it;  return
    for each choice available in this state:
        if the choice is valid (prune otherwise):
            make the choice             // choose
            backtrack(new state)        // explore
            undo the choice             // un-choose

The core backtracking templates

Subsets (power set)

def subsets(nums):
    res, path = [], []
    def go(i):
        if i == len(nums): res.append(path[:]); return
        path.append(nums[i]); go(i + 1)   # include
        path.pop();           go(i + 1)   # exclude
    go(0); return res                     # 2^n subsets

Permutations

def permutations(nums):
    res, path, used = [], [], [False] * len(nums)
    def go():
        if len(path) == len(nums): res.append(path[:]); return
        for i, x in enumerate(nums):
            if used[i]: continue
            used[i] = True; path.append(x)
            go()
            path.pop(); used[i] = False
    go(); return res                      # n! permutations

Combinations (choose k)

def combine(n, k):
    res, path = [], []
    def go(start):
        if len(path) == k: res.append(path[:]); return
        for x in range(start, n + 1):
            if n - x + 1 < k - len(path): break   # prune: not enough left
            path.append(x); go(x + 1); path.pop()
    go(1); return res                     # C(n, k)

Combination sum (reuse allowed)

def combination_sum(cands, target):
    cands.sort(); res, path = [], []
    def go(start, rem):
        if rem == 0: res.append(path[:]); return
        for i in range(start, len(cands)):
            if cands[i] > rem: break      # sorted: everything after is too big
            path.append(cands[i]); go(i, rem - cands[i]); path.pop()
    go(0, target); return res
  • Duplicates in the input: sort first, and skip nums[i] == nums[i-1] at the same depth (i > start) to avoid repeated answers.
  • Pruning is where backtracking gets its speed: check constraints as early as possible, order choices so likely ones come first, and stop when the remaining options cannot help.
  • Complexity is usually exponential (2n, n!, kn); backtracking is for small n or heavily constrained problems.
  • Branch and bound adds a bound on the best possible result of a branch and skips branches that cannot beat the best solution found so far (used for travelling salesman, knapsack, integer programming).

Real-world use cases

  • Parsers and compilers: recursive-descent parsing follows the grammar's recursion; regular-expression engines backtrack on alternatives.
  • File systems and documents: walking folders, rendering nested UI components, processing JSON/XML.
  • Puzzles and games: Sudoku and crossword solvers, chess engines (minimax with alpha-beta pruning).
  • Constraint satisfaction: timetabling, configuration tools, SAT solvers (DPLL/CDCL are backtracking with learning).
  • Generating test cases and combinations of options.

Practice questions

Q1. Fast power: compute xn medium divide and conquer 
def power(x, n):
    if n < 0: return 1 / power(x, -n)
    if n == 0: return 1
    half = power(x, n // 2)              # compute once, use twice
    return half * half * (x if n % 2 else 1)

O(log n) instead of O(n). The same idea powers modular exponentiation in cryptography.

Q2. Towers of Hanoi easy recursion 
def hanoi(n, src, dst, via):
    if n == 0: return
    hanoi(n - 1, src, via, dst)          # move n-1 out of the way
    print(f"move disk {n}: {src} -> {dst}")
    hanoi(n - 1, via, dst, src)          # put them back on top

T(n) = 2T(n-1) + 1 = 2n - 1 moves: provably optimal.

Q3. Subsets and subsets with duplicates medium backtracking

Include/exclude recursion (template above, animated in the call tree). With duplicates: sort, and in the loop-based version skip nums[i] == nums[i-1] when i > start.

Q4. Permutations with duplicates medium used[] + skip rule

Sort; skip nums[i] if it equals nums[i-1] and nums[i-1] is not currently used. That ensures equal values are always placed in the same relative order, so each distinct permutation appears once.

Q5. Generate all valid parentheses medium constrained generation 
def gen(n):
    res = []
    def go(s, open_, close):
        if len(s) == 2 * n: res.append(s); return
        if open_ < n: go(s + "(", open_ + 1, close)
        if close < open_: go(s + ")", open_, close + 1)   # never close more than opened
    go("", 0, 0); return res

Produces the Catalan number C(n) of strings; the constraints prune every invalid prefix.

Q6. Letter combinations of a phone number medium product of choices

For each digit choose one of its letters: recursion depth = number of digits, branching 3-4. O(4n·n). itertools.product does the same.

Q7. Word search in a grid medium DFS + backtracking 
def exist(board, word):
    R, C = len(board), len(board[0])
    def dfs(r, c, i):
        if i == len(word): return True
        if not (0 <= r < R and 0 <= c < C) or board[r][c] != word[i]: return False
        tmp, board[r][c] = board[r][c], "#"          # mark as used
        found = any(dfs(r + dr, c + dc, i + 1) for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)))
        board[r][c] = tmp                            # restore (backtrack)
        return found
    return any(dfs(r, c, 0) for r in range(R) for c in range(C))

For many words at once, put the words in a trie and walk the grid once (Word Search II).

Q8. N-Queens: count solutions fast hard sets / bitmasks

Track used columns, diagonals (r - c) and anti-diagonals (r + c) in sets for O(1) safety checks. Bitmasks make it faster still: free = ~(cols | d1 | d2) & full, and take the lowest bit with free & -free. There are 92 solutions for n = 8.

Q9. Sudoku solver hard constraint backtracking

Keep sets of used digits per row, column and box. Pick the empty cell with the fewest candidates (the "minimum remaining values" heuristic), try each candidate, recurse, undo on failure. The heuristic makes hard puzzles take milliseconds.

Q10. Palindrome partitioning medium backtracking + DP check

Return all ways to split a string into palindromes.

At position i, try every end j where s[i..j] is a palindrome (pre-compute a palindrome table with DP in O(n²)), recurse from j+1, then undo.

Q11. Restore IP addresses medium bounded choices

Choose 4 segments of length 1-3, each 0-255 with no leading zeros. Prune when the remaining length cannot fill the remaining segments (more than 3 × segments left, or fewer than 1 ×).

Q12. Flatten a nested list easy recursion on structure 
def flatten(x):
    if not isinstance(x, list): return [x]
    return [y for item in x for y in flatten(item)]
