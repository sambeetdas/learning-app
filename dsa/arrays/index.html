What is an array?

An array stores elements of the same size side by side in memory. Because of that, the address of element i is simply base + i × element_size, so reading or writing any index is O(1). Arrays are the most used data structure in computing, and many of the most important interview and real-world techniques (two pointers, sliding windows, prefix sums) are really just clever ways of walking an array.

OperationCostWhy

  • Static array: fixed size chosen at creation (C arrays, int[] in C#/Java).
  • Dynamic array: grows automatically: Python list, C# List<T>, Java ArrayList, C++ vector, JavaScript arrays.
  • 2-D arrays are stored row by row (row-major in C, C#, Python/NumPy by default): element (r, c) is at r × cols + c. Looping row by row is much faster than column by column because of the CPU cache.
  • Cache locality is the hidden super-power of arrays: neighbouring elements arrive in the CPU cache together, so linear scans are extremely fast in practice.

Dynamic arrays and amortised O(1) append

A dynamic array keeps a block with some spare capacity. When the block is full, it allocates a new one (typically 2× or 1.5× bigger), copies everything over, and frees the old block. Copying is expensive, but it happens so rarely that the average cost per append stays constant.

Watch a dynamic array grow

Why it works: copies happen at sizes 1, 2, 4, 8, ... n. Their total is 1 + 2 + 4 + ... + n < 2n, so n appends cost less than 3n writes in total. If the array grew by a fixed +10 instead of doubling, the total would be O(n²).

Strings

  • A string is an array of characters. In Python, Java, C# and JavaScript strings are immutable: "changing" one creates a new string, costing O(n).
  • Build strings by collecting pieces in a list and joining once ("".join(parts), StringBuilder).
  • Characters are numbers: ord('a') = 97. For lowercase letters, an array of 26 counters (count[ord(c) - 97]) is faster than a hash map.
  • Unicode: one visible character may be several code points or bytes (emoji, accents). Lengths and reversals can surprise you.
  • Common building blocks: frequency counting (anagrams), two pointers (palindromes), sliding window (substrings), hashing (duplicates), and the specialised algorithms on the string algorithms page (KMP, Z, Rabin-Karp, tries).
from collections import Counter
def is_anagram(s, t):            # O(n)
    return Counter(s) == Counter(t)

def is_palindrome(s):            # O(n) time, O(1) space, ignores non-alphanumerics
    i, j = 0, len(s) - 1
    while i < j:
        if not s[i].isalnum(): i += 1
        elif not s[j].isalnum(): j -= 1
        elif s[i].lower() != s[j].lower(): return False
        else: i += 1; j -= 1
    return True

Technique: two pointers

Use two indexes that move through the array according to a rule, instead of checking every pair. It turns many O(n²) problems into O(n).

Two pointers in action

pair_sum(sorted a, target):
    lo = 0, hi = n - 1
    while lo < hi:
        s = a[lo] + a[hi]
        if s == target: return (lo, hi)
        if s < target: lo = lo + 1        // only way to increase the sum
        else:          hi = hi - 1        // only way to decrease it
    return none

Why it is correct: when the sum is too small, a[lo] cannot be part of any answer with an element left of hi (those are even smaller), so discarding lo loses nothing. Each step discards one element: O(n).

Technique: sliding window

For problems about contiguous subarrays or substrings, keep a window [left, right] and update a running summary (sum, counts, set) as the window slides, instead of recomputing every window from scratch. Each element enters and leaves the window at most once: O(n).

Fixed size k

window = sum(a[0..k-1]); best = window
for right in k .. n-1:
    window += a[right] - a[right - k]   // add new, drop old
    best = max(best, window)

Variable size

left = 0
for right in 0 .. n-1:
    add a[right] to the window
    while window is invalid:
        remove a[left]; left += 1
    update the answer with window [left, right]

Longest substring without repeating characters

Signals for sliding window: "longest / shortest / count of subarrays or substrings that satisfy X", where X can be checked incrementally. If values can be negative and you need sums, a window may not work; use prefix sums + hash map instead.

Technique: prefix sums and difference arrays

Precompute running totals once, then answer any range-sum question in O(1).

Prefix sums

  • Subarray sum equals k: a subarray (i, j] sums to k exactly when P[j] - P[i] = k. Store counts of prefix sums seen so far in a hash map and look up P[j] - k: O(n), works with negatives.
  • 2-D prefix sums: S[r][c] = sum of the rectangle from (0, 0) to (r-1, c-1); any rectangle sum = S[r2][c2] - S[r1][c2] - S[r2][c1] + S[r1][c1].
  • Difference array (the reverse trick): to add v to every element in [l, r] many times, do D[l] += v; D[r+1] -= v, then take the prefix sum of D once at the end. Each range update becomes O(1). Used for booking systems, calendars, and "how many intervals cover each point".
  • Prefix XOR, prefix products, prefix min/max follow the same idea.

Technique: Kadane's algorithm (maximum subarray)

At every position, the best subarray ending here either extends the best one ending at the previous position, or starts fresh here. This is a tiny dynamic programme.

Maximum subarray sum

Variants: maximum product subarray (track both max and min, because a negative times a negative is positive), maximum circular subarray (total minus the minimum subarray), best time to buy and sell stock (a running minimum).

More array techniques

In-place reversal and rotation

Rotate right by k: reverse the whole array, then reverse the first k, then the rest. O(n) time, O(1) space.

def rotate(a, k):
    k %= len(a)
    def rev(i, j):
        while i < j: a[i], a[j] = a[j], a[i]; i += 1; j -= 1
    rev(0, len(a) - 1); rev(0, k - 1); rev(k, len(a) - 1)

Boyer-Moore majority vote

Find the element that appears more than n/2 times in O(n) time and O(1) space: keep a candidate and a counter; equal elements add 1, different ones subtract 1; when the counter hits 0, adopt the current element.

def majority(a):
    cand, cnt = None, 0
    for x in a:
        if cnt == 0: cand = x
        cnt += 1 if x == cand else -1
    return cand          # verify with a second pass if a majority is not guaranteed

Matrix traversal

  • Spiral order: keep four boundaries (top, bottom, left, right) and shrink them after each side.
  • Rotate 90° clockwise in place: transpose (swap m[i][j] and m[j][i]), then reverse each row.
  • Grids as graphs: each cell has up to 4 neighbours; flood fill and islands are BFS/DFS (see graphs).

Cyclic sort (values in a known range)

When values are 1..n, put each value at index value-1 by swapping. Afterwards, the first index i with a[i] != i+1 reveals the missing / duplicate number. O(n) time, O(1) space.

Intervals

Sort by start time, then sweep: merge overlapping intervals, insert a new interval, or count overlaps. Sorting dominates: O(n log n).

def merge(intervals):
    intervals.sort()
    out = []
    for s, e in intervals:
        if out and s <= out[-1][1]: out[-1][1] = max(out[-1][1], e)
        else: out.append([s, e])
    return out

Practice questions

Q1. Two Sum II (sorted input) easy two pointers

Given a sorted array and a target, return the indexes of two numbers that add up to the target.

Approach

Opposite-end pointers, exactly as in the animation. Too small → move left pointer right; too big → move right pointer left.

Complexity

O(n) time, O(1) space. (Unsorted input: use a hash map instead, see hashing.)

Q2. Best time to buy and sell stock easy running minimum

prices[i] is the price on day i. Buy once and sell later; maximise the profit.

Approach

Scan once, remembering the cheapest price so far. Selling today gives price - min_so_far.

def max_profit(prices):
    lo, best = float('inf'), 0
    for p in prices:
        lo = min(lo, p)
        best = max(best, p - lo)
    return best

Complexity

O(n) time, O(1) space.

Q3. Move zeroes easy read/write pointers

Move all zeroes to the end while keeping the order of the other elements, in place.

def move_zeroes(a):
    w = 0                          # next position to write a non-zero
    for r in range(len(a)):
        if a[r] != 0:
            a[w], a[r] = a[r], a[w]
            w += 1

Complexity

O(n) time, O(1) space.

Q4. Maximum subarray medium Kadane

Find the contiguous subarray with the largest sum.

Approach

Kadane's algorithm (animated above): cur = max(x, cur + x); best = max(best, cur). Divide and conquer also works in O(n log n), but Kadane is simpler and faster.

Complexity

O(n) time, O(1) space.

Q5. Product of array except self medium prefix / suffix

Return an array where out[i] is the product of all elements except a[i], without using division.

Approach

out[i] = (product of everything left of i) × (product of everything right of i). Fill left products in one pass, then multiply by a running right product in a backward pass.

def product_except_self(a):
    n = len(a); out = [1] * n
    left = 1
    for i in range(n): out[i] = left; left *= a[i]
    right = 1
    for i in range(n - 1, -1, -1): out[i] *= right; right *= a[i]
    return out

Complexity

O(n) time, O(1) extra space (besides the output).

Q6. Container with most water medium two pointers

Heights h[i] form vertical lines. Choose two lines that, with the x-axis, hold the most water.

Approach

Start with the widest pair. Area = width × min(h[l], h[r]). Always move the shorter line inwards: keeping it can never give a bigger area, because the width only shrinks and the height is capped by it.

l = 0, r = n - 1, best = 0
while l < r:
    best = max(best, (r - l) * min(h[l], h[r]))
    if h[l] < h[r]: l += 1 else: r -= 1

Complexity

O(n) time, O(1) space.

Q7. 3Sum medium sort + two pointers

Find all unique triplets that sum to zero.

Approach

Sort. Fix each element a[i] (skipping duplicates), then run the two-pointer pair search for -a[i] on the part to its right, skipping duplicate values as the pointers move.

def three_sum(a):
    a.sort(); res = []
    for i in range(len(a) - 2):
        if i and a[i] == a[i - 1]: continue
        l, r = i + 1, len(a) - 1
        while l < r:
            s = a[i] + a[l] + a[r]
            if s < 0: l += 1
            elif s > 0: r -= 1
            else:
                res.append([a[i], a[l], a[r]]); l += 1; r -= 1
                while l < r and a[l] == a[l - 1]: l += 1
    return res

Complexity

O(n²) time, O(1) extra space (besides sorting). This is optimal for the general problem in practice.

Q8. Subarray sum equals k medium prefix sums + hash map

Count subarrays whose sum is exactly k. Values may be negative.

Approach

A sliding window fails with negatives. Instead: a subarray ending at j sums to k when some earlier prefix sum equals P[j] - k. Keep a hash map of how often each prefix sum has occurred.

def subarray_sum(a, k):
    count, s, seen = 0, 0, {0: 1}
    for x in a:
        s += x
        count += seen.get(s - k, 0)
        seen[s] = seen.get(s, 0) + 1
    return count

Complexity

O(n) time and space.

Q9. Longest substring without repeating characters medium sliding window

Return the length of the longest substring with all distinct characters.

Approach

Variable sliding window with a map of each character's last index (animated above). When the new character was seen inside the window, jump left past it.

Complexity

O(n) time, O(alphabet) space.

Q10. Minimum window substring hard sliding window + counts

Find the smallest substring of s that contains every character of t (with multiplicity).

Approach

Count what t needs. Expand right until the window satisfies all needs (track how many distinct characters are fully satisfied); then shrink left as long as it stays valid, recording the smallest window.

from collections import Counter
def min_window(s, t):
    need, have = Counter(t), {}
    formed, req = 0, len(need)
    best = (float('inf'), 0, 0); l = 0
    for r, c in enumerate(s):
        have[c] = have.get(c, 0) + 1
        if c in need and have[c] == need[c]: formed += 1
        while formed == req:
            if r - l + 1 < best[0]: best = (r - l + 1, l, r)
            have[s[l]] -= 1
            if s[l] in need and have[s[l]] < need[s[l]]: formed -= 1
            l += 1
    return "" if best[0] == float('inf') else s[best[1]:best[2] + 1]

Complexity

O(|s| + |t|) time.

Q11. Trapping rain water hard two pointers / prefix max

Given bar heights, how much water is trapped after rain?

Approach

Water above bar i = min(max height to its left, max height to its right) - h[i]. Two pointers: move the side with the smaller running max, because that side's water level is already decided.

def trap(h):
    l, r, lmax, rmax, water = 0, len(h) - 1, 0, 0, 0
    while l < r:
        if h[l] < h[r]:
            lmax = max(lmax, h[l]); water += lmax - h[l]; l += 1
        else:
            rmax = max(rmax, h[r]); water += rmax - h[r]; r -= 1
    return water

Complexity

O(n) time, O(1) space. (A monotonic stack solution also works, see stacks.)

Merge all overlapping intervals.

Q13. Spiral matrix medium simulation 
def spiral(m):
    res = []
    top, bot, left, right = 0, len(m) - 1, 0, len(m[0]) - 1
    while top <= bot and left <= right:
        for c in range(left, right + 1): res.append(m[top][c])
        top += 1
        for r in range(top, bot + 1): res.append(m[r][right])
        right -= 1
        if top <= bot:
            for c in range(right, left - 1, -1): res.append(m[bot][c])
            bot -= 1
        if left <= right:
            for r in range(bot, top - 1, -1): res.append(m[r][left])
            left += 1
    return res

Complexity

O(rows × cols).

Q14. Range addition (many range updates) medium difference array

Start with n zeros and apply q updates "add v to every index in [l, r]". Return the final array.

Approach

Naively each update is O(n): O(nq) total. With a difference array, each update is two writes; one prefix sum at the end rebuilds the array.

def apply(n, updates):
    d = [0] * (n + 1)
    for l, r, v in updates:
        d[l] += v; d[r + 1] -= v
    out, run = [], 0
    for i in range(n): run += d[i]; out.append(run)
    return out

Complexity

O(n + q).
